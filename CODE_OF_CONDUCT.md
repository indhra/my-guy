# Code of conduct

Be respectful and constructive. Welcome people with different experience levels and backgrounds. Critique ideas and code without personal attacks, harassment, threats, or disclosure of private information. Maintainers may edit or remove harmful contributions and restrict participation when necessary.

For a public discussion, open a GitHub issue without personal or sensitive details. For a sensitive conduct concern, use the repository's [private advisory form](https://github.com/indhra/my-guy/security/advisories/new) and state that it is a conduct report. Maintainers will handle reports privately, review context fairly, and avoid sharing identifying details beyond those needed to respond. For software vulnerabilities, follow [SECURITY.md](SECURITY.md).
